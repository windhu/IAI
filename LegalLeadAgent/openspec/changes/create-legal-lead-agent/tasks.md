# Tasks

## 1. 项目基础与来源核验

- [ ] 1.1 建立 Python 项目、SQLite 存储及命令行运行入口；通过初始化、重启读取和失败提示测试验证持久化。
- [ ] 1.2 建立来源清单及默认禁用规则，逐项核实目标用途、授权、访问限制及日期；测试未核实来源不会发出请求，状态显示未启用。
- [ ] 1.3 核验至少一个可定时使用的具体来源，记录依据并实现其适配器；用真实允许访问的样本验证发布时间、链接和内容提取。若无法核实，保持该任务未完成，不将手动提交当成自动采集。
- [ ] 1.4 评估抖音、小红书、微信及招聘平台是否可用于本用途并记录接入条件；验证未授权时保持禁用且不绕过限制。

## 2. 手动录入与隐私

- [ ] 2.1 实现公开链接及摘要命令行录入，验证 HTTP(S) 校验、提交时间和无法自动读取时的手动录入；不自动访问任意链接。
- [ ] 2.2 实现最小化字段、敏感内容拒绝或安全处理、存储访问限制及清理期限；测试私人联系方式、医疗细节不会出现在数据库摘要和邮件中。
- [ ] 2.3 编写来源准入及手动录入说明，明确不自动联系、不处理私人社交空间，按文档验证提交和状态查看。

## 3. 分类、去重与排序

- [ ] 3.1 实现个人求助、法律服务采购、招聘潜在机会和待核实分类；测试招聘不被标为明确外聘需求，缺失地区与时间保持未知。
- [ ] 3.2 实现 URL 与可可靠匹配的同企业同岗位去重，并排除明确截止的采购公告；测试重复来源、不同岗位、截止前后及未知截止时间。
- [ ] 3.3 实现基于地区、业务、需求明确程度和时效的可解释筛选排序；测试明确求助与招聘弱信号、未知字段、无关线索和同分稳定排序，不产生成交概率。

## 4. 每日邮件和运行状态

- [ ] 4.1 实现北京时间批次、纯文本邮件内容及最多十条上限；测试零条、少于十条、超过十条、缺失字段及来源失败的实际输出。
- [ ] 4.2 实现加密邮件发送、环境变量配置、持久发送状态和状态查看；测试发送成功、明确失败、结果未知、已成功批次重复运行及用户手动重试。
- [ ] 4.3 文档化运行环境、定时器、邮箱密钥配置、发送失败排查与停用流程；在测试环境按说明验证定时触发和状态查看，不记录凭据。

## 5. 集成验收

- [ ] 5.1 使用授权来源样本及手动提交链接运行完整流程，验证分类、去重、排序、每日邮件及来源故障提示；使用测试邮箱或邮件捕获服务核对实际消息。
- [ ] 5.2 在选定的受控运行主机上验证北京时间定时执行、重启后状态恢复及真实邮箱投递；没有主机、邮箱或来源授权时明确记录阻塞，不标记验收通过。
