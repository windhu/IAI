- [x] 2.3 实现保养项目多选、自定义项目、可选费用与备注表单；通过浏览器测试验证一条多项目记录的保存、字段错误提示及失败后输入保留。
- [x] 2.4 实现加油日期、里程、金额、可选升数和备注表单；通过浏览器测试验证省略升数仍能保存、非法金额被拒绝、重开应用后记录存在。
- [x] 2.5 实现日期降序及同日稳定排序、详情、编辑、确认删除、里程走势核对提示；通过测试验证补录旧记录、矛盾里程可确认保存、取消删除不修改和确认删除仅影响目标记录。
- [x] 2.6 在使用说明中记录单车、公里、人民币及本地存储边界；核对文档字段与两个实际表单一致。

## 5. 本机仪表盘识别

- [x] 5.1 集成 Tesseract.js，核对所选版本的资源清单及许可证，自托管 worker、WASM 和模型并显式配置路径；在浏览器请求检查中验证只下载同站静态资源，根路径与子目录部署都能初始化识别。
- [x] 5.2 实现拍照和相册入口、方向处理、总里程区域裁剪及临时图片清理；浏览器测试验证裁剪针对选择区域、取消保留表单，相机不可用时仍能选图或手输。
- [x] 5.3 实现数字边界解析、可信度判断、候选确认及手动修正，不拼接多数字、不去掉小计小数点、不取最大值；通过有效整数、多数字、小数、低可信度及失败测试验证候选和拒绝行为，确认前不覆盖表单或保存记录。
- [x] 5.4 实现识别进度、取消、过期结果屏蔽和失败提示；测试验证更换图片、离开表单及取消后旧结果无效，worker/临时图片被清理，手输始终可用。
- [x] 5.5 实现 OCR 独立资源准备与版本化缓存，检查资源真实存在和初始化成功后才显示就绪；浏览器测试验证完整准备后断网识别，以及资源缺失或被回收时明确提示、不调用联网 OCR、仍能手输保存。
- [x] 5.6 使用允许本机测试的真实仪表盘照片核对已知总里程，覆盖清晰总里程、七段数字、多数字、反光和模糊样本，记录候选正确/拒绝/错误及耗时并据此确定保守可信度门槛；验证清晰样本确实输出正确待确认总里程，不能用模拟返回值或“识别出任意数字”替代验收，不上传照片。
- [x] 5.7 在使用说明中记录裁剪、核对总里程、首次模型准备及失败回退流程，记录资源大小和实际测得的性能限制；对照实际界面和照片验证结果审阅说明，不声称未经测量的准确率。
