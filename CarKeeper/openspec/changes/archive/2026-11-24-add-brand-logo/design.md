# Design

## Context

动机见 [proposal.md](proposal.md)。首页结构在 `src/ui/App.tsx` 的 `Home` 中定义：`page-header` 标题区下方依次为两个记录入口、链接卡片、“使用与离线”卡片，以及一段说明文字。导航使用同一文档内的哈希路由，因此“冷启动”就是页面加载一次。service worker 会预缓存构建出的 JS、CSS 和 HTML（见 `vite.config.ts` 中的 `globPatterns`）。现有浏览器测试大多在页面加载后立即点击或填写。

## Goals / Non-Goals

**Goals:**

- 徽标只有一个实现来源，在三个位置复用，并且天然离线可用。
- 启动画面只是覆盖层，不阻塞记录读取和界面渲染。
- 不影响现有功能和测试的稳定性。

**Non-Goals:**

- 不使用外部图片文件或网络字体，不把文字转成路径。
- 不修改 manifest、桌面图标或系统启动画面。
- 不在页面之间添加转场动画。

## Decisions

### 1. 内联 SVG 组件 `BrandLogo`

新增 `src/ui/BrandLogo.tsx`，用内联 SVG 绘制徽标：左侧是蓝色圆形，内含白色“峰”字；右侧是深色粗体“峰哥出品”，整体为圆角胶囊外框。主色沿用现有的 `--blue`。组件提供 `size` 属性（小号用于标题旁和页脚，大号用于启动画面）。

- 内联 SVG 会被打包进已预缓存的 JS 中，因此无需额外请求，离线显示与在线一致，在高分屏上也保持清晰。相比之下，单独的 PNG 或 SVG 文件需要额外请求和缓存配置，且只能在 `<img>` 中缩放。
- 文字使用系统中文字体（`system-ui`、`PingFang SC`、`Noto Sans SC` 等，与现有 `:root` 字体栈一致），Android 自带的 Noto Sans CJK 可以正常显示。不同系统的字形会略有差异，但能避免引入数 MB 的中文字体文件。
- 无障碍处理：当组件作为有意义的内容出现时，使用 `role="img"` 和 `aria-label="峰哥出品"`。当它是装饰性重复时（例如页脚署名中已有文字），传入 `decorative` 属性，此时设置 `aria-hidden="true"`。

### 2. 首页布局

- 标题区改为 flex 布局：`h1` 在左，小号徽标在右，二者垂直居中，并允许换行（`flex-wrap`）。在窄屏上徽标会换到下一行，避免横向溢出。
- 在首页说明文字之后增加页脚：装饰性小徽标加上可见文字“峰哥出品”。读屏软件只会朗读其中的文字，不会重复朗读徽标。

### 3. 启动画面 `LaunchScreen`

- 在 `App` 根部渲染 `LaunchScreen`：全屏固定定位，使用与 manifest `background_color` 相同的浅色背景，中间显示大号徽标和“爱车记录”。整个覆盖层设置 `aria-hidden="true"`，因为它只是短暂的装饰，首页标题仍然可以被读屏软件读到。
- 因为它是覆盖层，`RecordsProvider` 和首页会在其下方照常加载，读取记录不会被推迟。
- 消失时机：在“记录读取结束（成功或失败）”和“挂载后至少 600 ms”这两个条件都满足时开始淡出，淡出耗时 200 ms。无论读取是否完成，最晚在挂载后 1.5 s 强制淡出，避免存储异常时一直挡住界面。最短显示时间用来防止画面一闪而过；最长时间满足规格中“1.5 秒内”的要求。
- 轻点（`pointerdown`）后立即移除，不等待淡出。
- 用户开启 `prefers-reduced-motion` 时不播放淡出动画，直接移除。
- 用一个模块级标志记录启动画面是否已显示过。哈希路由切换不会重新挂载 `App`，标志只用于防止开发模式下 `StrictMode` 的二次挂载导致重复显示。整页刷新才算新的冷启动，届时会再次显示。

备选方案：把静态启动画面写在 `index.html` 中，这样在 JS 加载前就能显示。但这会让徽标标记在 HTML 和组件中各维护一份。考虑到 JS 已经预缓存，本地加载很快，因此选择只用组件实现。

### 4. 测试

- 新增浏览器测试，覆盖以下场景：首页顶部和底部的徽标及其文字替代、手机宽度下无横向溢出、冷启动时出现启动画面且在 1.5 s 内消失、轻点后立即关闭、页面内导航不再出现，以及离线重启后徽标正常显示。
- 现有测试在启动画面期间点击时，Playwright 会等待目标元素不被遮挡后再点击，因此不需要修改。`fill` 不受遮挡影响。需要运行一次完整测试套件来确认。

## Risks / Trade-offs

- [不同手机的系统字体导致徽标字形不一致] → 使用粗体无衬线字体栈，并保证胶囊尺寸能容纳较宽的字形；真机验收时确认显示效果。
- [启动画面让每次打开多等约 0.6 s] → 只在冷启动时出现，轻点即可跳过，上限为 1.5 s。
- [覆盖层期间的点击被吃掉] → 轻点只会关闭启动画面，不会穿透到下方按钮，避免误触。
- [浏览器测试受覆盖层影响] → 依赖 Playwright 的遮挡等待，并运行完整测试套件验证。

## Migration Plan

纯前端界面改动，没有数据迁移。重新构建后部署；已打开应用的用户会看到“有新版本可用”的提示，更新后生效。回滚时部署上一版构建产物即可。
