# Proposal

## Why

爱车记录在桌面端将内容限制在 560px，造成较大留白；手机端文字和内容区也有提升可读性的空间。需要在不同屏幕尺寸下更好地利用空间，同时保持快速记录体验。

## What Changes

- 缩小手机端页面边距并适度提高正文可读性。
- 在平板和桌面端扩大首页和历史等内容区，表单保持适合阅读和填写的宽度。
- 保持响应式布局、触控尺寸、浏览器文字缩放、底部导航及现有记录功能。
- 不改变数据模型、路由、离线功能或部署方式。

## Capabilities

### New Capabilities

- `responsive-layout`: 规定不同屏幕尺寸下的页面宽度、文字可读性和可操作性。

### Modified Capabilities

无。

## Impact

- 调整 `src/ui/styles.css`，必要时调整页面结构。
- 扩展现有浏览器布局测试，验证手机、平板和桌面视口。
- 不新增依赖、外部资源或数据迁移。
