# Proposal

## Why

照片水印应用在桌面端将内容限制在 720px，造成较大留白；手机端也可以适度提高正文可读性和空间利用率。更灵活的布局可让照片预览和控制项更易使用。

## What Changes

- 缩小手机端页面边距并适度提高正文可读性。
- 扩大桌面工作区，在足够宽的屏幕上并排显示预览与控制项；窄屏继续纵向排列。
- 保持预览与导出比例一致、触控友好、语言切换和单文件离线分发。
- 不改变照片处理、导出语义或部署方式。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `web-app-delivery`: 扩展手机友好布局要求，覆盖平板和桌面宽度、文字可读性及响应式工作区。

## Impact

- 调整 `web/index.html` 中的布局及必要的预览尺寸处理。
- 扩展浏览器测试，验证响应式布局、语言切换和照片预览与导出。
- 继续使用自包含的单个 HTML 文件，不新增外部依赖。
